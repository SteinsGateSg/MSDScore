Reference-Free Image Caption Evaluation

Multi-Scale Distributional Scoring for Faithful Captions

MSD-Score evaluates image captions without references by comparing patch-level visual evidence and token-level textual claims as local distributions, then fusing them with global image-text similarity.

Abstract

A deterministic metric for local grounding errors.

Evaluating captions without references is difficult because global embedding similarity often misses hallucinated objects, missing attributes, or incorrect relations. MSD-Score models image patches and text tokens as von Mises-Fisher mixtures on the unit hypersphere. A length-aware bi-directional KL divergence captures complementary coverage and support failures, while Soft-MSD adaptively combines this local discrepancy with global similarity. The result is a reproducible, decomposable signal for offline caption evaluation.

Method

From point similarity to distributional alignment.

01

Local representations

Extract normalized image patch embeddings and caption token embeddings instead of collapsing each modality into one vector.

02

vMF mixtures

Fit fixed-kappa hyperspherical mixtures to model semantic modes under the high-dimensional, few-token regime.

03

Soft-MSD fusion

Penalize local divergence only when global candidate scores are uncertain, preserving robust global relevance.

Code

Run Soft-MSD on a pairwise benchmark.

python metrics/vMF_MSD_Score/coco_eval_cf.py \
  --data_json data/coco_cf/coco_cf_easy.json \
  --judge_model openai/clip-vit-large-patch14 \
  --device cuda

The code release contains the core vMF/Soft-MSD metric, COCO-CF, SugarCrepe, CapArena, DocENT scripts, GMM ablations, and caption generation utilities.
